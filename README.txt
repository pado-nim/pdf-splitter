PDF 분할기 v1.0.0
=================

[설치]  1_install.bat 더블클릭  (처음 한 번만)
[실행]  바탕화면 "PDF 분할기"  또는  2_run.bat
        PDF 우클릭 > 보내기 > "PDF 분할기" 로도 열려요

[나누는 방식]
  - 페이지 지정 : "100, 250"  → 1~100 / 101~250 / 251~끝
                  "1-100, 300-400" → 적은 구간만 뽑기
  - 쪽 수로     : N쪽씩, 또는 N개로 똑같이
  - 용량 기준   : 조각마다 N MB 이하가 되도록 자동으로 맞춤 (업로드 제한용)

결과는 원본 옆 "파일이름_분할" 폴더에 저장돼요. 원본은 그대로예요.
